# HL7-to-FHIR Patient Data Mapping

## Project Overview

This beginner-level project demonstrates the basic concept of healthcare interoperability by using Python to extract patient information from a simplified HL7 message and map the information to a simplified FHIR Patient resource.

## Objective

To understand how patient information can be transformed between healthcare data standards and demonstrate the role of HL7 and FHIR in healthcare interoperability.

## Technologies Used

- Python
- Jupyter Notebook
- HL7
- FHIR

## Project Workflow

1. Create a simplified HL7 patient message
2. Identify relevant HL7 segments and fields
3. Extract basic patient information
4. Map the extracted information to corresponding FHIR Patient fields
5. Display the mapped patient information
6. Perform basic validation

## Key Concepts

### HL7

HL7 is a set of standards used for exchanging healthcare information between different healthcare systems.

### FHIR

FHIR is a healthcare interoperability standard that represents healthcare information using standardized resources such as the Patient resource.

### Interoperability

Interoperability allows different healthcare systems to exchange and understand healthcare information in a standardized manner.

## Project Outcome

The project demonstrates a simplified EMR-to-data-exchange workflow and shows how basic patient demographic information can be mapped from an HL7-based message to a FHIR Patient structure.

## Limitations

This is an educational prototype using simplified HL7 and FHIR concepts. It does not connect to a real EMR, FHIR server, or production healthcare system.
